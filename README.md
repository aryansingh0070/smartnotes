# SmartNotes

SmartNotes is a simple and responsive note-sharing website built using HTML, CSS, and JavaScript. It provides an easy-to-use interface for browsing notes and accessing educational resources.

## Features

* Clean and responsive user interface
* Notes browsing page
* Contact page
* Mobile-friendly design
* Fast and lightweight website
* Easy navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
smartnotes/
│
├── index.html
├── notes.html
├── contact.html
├── css/
├── js/
├── assets/
└── README.md
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/aryansingh0070/smartnotes.git
```

2. Open the project folder:

```bash
cd smartnotes
```

3. Open `index.html` in your browser.
